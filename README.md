# prep-mate-presentation

Site static pentru **Prep Mate** (GitHub Pages).

## Conținut

- `index.html` — pagină de start
- `privacy/index.html` — **politica de confidențialitate** (URL pentru Google Play)
- `.nojekyll` — site static fără Jekyll

## GitHub Pages

**Settings** → **Pages** → **Source**: branch **main** (sau `master`), folder **`/` (root)** → Save.
